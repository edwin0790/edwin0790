### What I do

I help technical teams bring order to complex, fast-growing systems — from
bare-metal firmware and industrial integration to AI-powered software
products — with a focus on solid architecture and disciplined engineering
practice.

Two threads run through most of my work:

- **Embedded / industrial / IoT** — C/C++, RTOS, Embedded Linux
  (Yocto, Buildroot, PetaLinux), OPC-UA, ISOBUS, LoRaWAN. The OT↔IT bridge:
  making machines talk to the systems that manage them.
- **Engineering discipline for AI-assisted software** — full-stack and
  DevOps work where AI coding agents are part of the delivery pipeline, not
  a shortcut around good practice. Recent hands-on focus: stabilizing a
  fast-growing MVP and defining an evaluation harness for coding agents.

### Currently

🔭 Working on an ERP platform with an AI-driven commercial assistant —

🌱 Exploring how to evaluate AI coding agents in a repeatable way — a
harness, not a vibe check.

⚙️ Long-running interest: Embedded Linux BSPs, RTOS driver design, and
industrial protocol bridges (OPC-UA, ISOBUS, LoRaWAN).
